# Tag tiles

This folder contains the **blank tile**, a cube side without a tag:

| File | Use |
|---|---|
| [`tile-blank.3mf`](tile-blank.3mf) | Print a plain side, or open it in your slicer |
| [`tile-blank.step`](tile-blank.step) | Add your own tag or design in CAD |

The tile is 44 × 44 × 6.8 mm, modelled in print orientation. The tag goes on its **underside**, the face that lies on the bed.

## Tiles with AprilTags

> **The tiles with tags (every ID of every family) are in the [latest release](https://github.com/aaronhary/april-cube-3DP/releases/latest), as one zip per family.**

Each zip holds Bambu Studio plates with 16 tiles each (IDs 0–15, 16–31, …), set up for the Bambu Lab A1. Each tile is this blank tile:
- with the tag inlaid 0.2 mm (one layer) into the underside, as a separate black part,
- with its ID number engraved 0.2 mm into the upper side.
